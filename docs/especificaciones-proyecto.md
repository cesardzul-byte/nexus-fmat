# Universidad Autónoma de Yucatán
## Facultad de Matemáticas

### Proyecto integrador de Desarrollo de Aplicaciones Web

---

## 1. Especificaciones para la revisión y entrega del proyecto

- La aplicación web se entregará en equipos (máximo 4 integrantes).
- Se realizarán revisiones (3) del proyecto en las fechas especificadas.
- Se entregará el documento de requisitos.
- Se entregará el documento del modelo relacional de la base de datos.
- En la última revisión se entregará la aplicación web y la base de datos.

## 2. Las entregas se subirán en la plataforma del curso

La propuesta deberá contemplar (**documento de requisitos**):

- El nombre de la aplicación.
- Una descripción general del problema o necesidad que atenderá.
- Una explicación general de la funcionalidad principal de la aplicación.
- La integración futura del FrontEnd y el BackEnd.
- El manejo de una base de datos con cinco o más tablas, por ejemplo: usuarios, productos, clientes, ventas u otras entidades relacionadas con el proyecto.

## 3. La puntuación correspondiente a cada uno de los productos entregados en las fechas de revisión acordados será la siguiente:

| Producto | Puntaje |
|---|---|
| Descripción general del problema o necesidad que atenderá (documento de requisitos) | 3 puntos |
| Diagramas de entidad relación (segunda revisión) | 2 puntos |
| Codificación (primera, segunda y tercera revisión) | 3 puntos |
| Trabajo en equipo (integración, asistencia en las revisiones; en equipos se realizará una coevaluación indicada por el profesor) | 2 puntos |

## 4. Para la evaluación de la fase de codificación se considerarán los siguientes aspectos (esto es sobre los 20 puntos faltantes):

| Aspecto | Porcentaje |
|---|---|
| Funcionalidad | 40 % (8 puntos) |
| Implementación de los temas del curso | 20 % (4 puntos) |
| Modularidad | 20 % (4 puntos) |
| Presentación de la aplicación (Interfaz) | 20 % (4 puntos) |

## 5. Fechas para las revisiones y especificaciones de entregas:

- **29/10/2026:** Requisitos del software, diagrama de entidad relación, primer avance de la codificación, al menos el index, autentificación y una funcionalidad.
- **12/11/2026:** Codificación y avance del proyecto – codificación de las demás funcionalidades y componentes.
- **26/11/2026:** Integración y entrega final de la aplicación Web.

En la segunda y/o entrega final, deberán incorporar los siguientes componentes:

- **CREATE:** Registrar nueva información en la base de datos.
- **READ:** Consultar y presentar información almacenada.
- **UPDATE:** Modificar registros existentes.
- **DELETE:** Eliminar o desactivar información de acuerdo con el diseño del sistema.
- **Autenticación:** Incorporar un mecanismo para identificar a los usuarios que acceden al sistema.
- **Sesiones:** Utilizar sesiones para conservar el estado del usuario autenticado durante la navegación.
- **Documentación:** Manual de usuario y manual técnico del proyecto.
